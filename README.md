**Valley Mail** is an original bush-pilot flight game that runs offline in a desktop browser. Fly a prop plane down a river valley: take off from a grass strip, thread the glowing mail rings, drop a parcel over the village, and land at the next airstrip before your fuel and your hull run out. Three sorties — First Post, Cargo Drop and the Dusk Run — plus an endless free-flight mode. The chase view shows the aircraft over patchwork fields and a winding river, with a full instrument HUD: airspeed and altitude tapes, a compass strip, an artificial horizon, throttle, fuel and hull readouts.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. To produce the hand-in output instead: `mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts`.
